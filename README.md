# AI Chart Scanner Website

A simple front-end website for an AI-powered chart scanner with a strategy library.

## Features
- Scanner dashboard with multi-asset opportunity cards
- Strategy library section with reusable system cards
- AI signal explanation panel
- Responsive dark trading UI

## Run locally
Open `index.html` directly in a browser, or serve the folder using a local static server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files
- `index.html` — page structure
- `styles.css` — all styling for the dashboard
- `app.js` — mock scanner and strategy data rendering
